SOS receiver pairing

Create a one-time six-character invitation, then enter it on the second phone at SOS Receiver. A new invitation immediately replaces the old receiver and expires after 10 minutes.

Share this one-time code privately. It is not stored permanently. Generating another code disconnects the previous receiver.

Optional hands-free SOS triggers

These are disabled by default. They work only while Blind mode is open and visible on a supported phone. Shake sensing stays on the device; voice wake-word recognition may send audio to the browser's speech provider. Each automatic trigger has a cancellation window.

Disabled. Three strong, separate shakes within a short window are required.

Disabled. Say “Daredevil SOS”, then “Confirm SOS”.

Voice SOS uses the browser's continuous speech-recognition API, not Gemini. The microphone is monitored only in the visible Blind mode page. English: say “Daredevil SOS”, then “Confirm SOS”. Bangla: say “ডেয়ারডেভিল এসওএস”, then “নিশ্চিত করুন” or “এসওএস পাঠান”. Say “Cancel SOS” / “এসওএস বাতিল” during the countdown to stop it. Recognition availability depends on Android/Chrome and installed speech services. Automatic mode records a short clip and sends it to Gemini to detect Bangla, English or mixed speech. Browser mode uses the selected language first and switches to Gemini if it fails. Audio is processed externally; do not speak confidential information.
