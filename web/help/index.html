GUIDE & SUPPORT

Help and instructions

How to use the camera, ask a question, get speech working and pair SOS.

1. Main actions and spoken Help

DESCRIBE — understand the scene

Tap DESCRIBE. The configured camera source (phone camera or ESP32-CAM) captures the image used for analysis. When the ESP32-CAM burst mode is enabled, the app can select the sharpest of up to three frames. Keep the camera steady and make sure the subject is in the frame. A photo can still be unclear, dark or partly blocked.

ASK AI — ask about the current view

Tap ASK AI, wait for the listening cue, then ask one clear question in Bangla, English or a mixture. Pause when finished. Automatic voice mode sends a short recording to Gemini for multilingual transcription. You can also type a question on the normal Home page.

SOS — notify your paired receiver

SOS needs confirmation: tap once to arm it, then tap again within five seconds. It alerts only the receiver paired in advance. It does not silently contact emergency services or guarantee delivery.

REPEAT — hear the last answer again

Tap REPEAT in Blind mode to hear the latest answer again. SPOKEN HELP is a separate control below the four main buttons and reads the basic instructions aloud.

2. Use Blind mode

Open Blind mode for a full-screen 2-by-2 layout with four main controls: DESCRIBE, ASK AI, SOS and REPEAT. SPOKEN HELP is a separate button below the grid; it reads instructions aloud and is not a text overlay or one of the four main actions.

SOS requires confirmation: tap once to arm it, then tap again within five seconds. URL shortcuts pre-arm SOS but never send an alert on their own. To leave Blind mode, edit the browser address and remove /blind/, or navigate directly to /action/. There is deliberately no exit control on the Blind mode screen.

3. Camera setup and photo fallback

Start in Devices for connection instructions. The current ESP32-CAM address field is in Admin → Camera & Devices. Enter the base address assigned by your own router, for example YOUR_ESP32_IP. The app adds http:// automatically and requests the camera's /capture endpoint. The phone and camera must be on a network that allows that request. A local private IP works only on its local network; the hosted website cannot reach your home or lab camera from anywhere in the world.

On the normal Home page, use “Use phone camera / upload photo” when the ESP32-CAM is unavailable. Choose a clear JPEG, PNG or WebP image. Never expose an unauthenticated camera web server directly to the public Internet.

4. Voice input and language

The microphone needs a secure HTTPS website (or localhost on a development computer). Plain HTTP LAN addresses are not secure contexts for browser microphone access.

Recommended Automatic mode records a short clip and sends it to Gemini to recognise Bangladeshi Bengali, English or mixed Bangla-English. It translates Bengali words into English for the AI question and preserves English words. Browser-first recognition is optional in Admin; choose Bangla (Bangladesh) for its language and the app falls back to Gemini if it reports no speech or a service/language failure.

Audio is processed externally in Automatic mode. Do not speak passwords, private details or confidential information. The recording stops after a pause or a short time limit. Gemini quota applies.

AI response language and microphone input mode are separate Admin settings. Incoming Bangla is translated to English for the AI question; AI replies default to English. Set AI response language to বাংলা (Bangladesh) in Admin for Bengali answers. Bengali spoken answers also need a Bengali text-to-speech voice installed on the phone; the app prefers an installed Bengali voice and Admin reports whether one is available. If no Bengali voice appears, install Bengali speech data in Android text-to-speech settings.

5. Models, automatic fallback and your own key

The Admin model list is ranked for image understanding: models that can analyse camera photos appear before lower-cost Flash or Flash-Lite options. It is not a list of image-generation models. An image-generation-only model creates a picture and is not suitable for describing a photo from the camera.

When a model-specific limit, overload or temporary availability error occurs, the Worker tries other compatible Gemini models. This is best-effort fallback. Google applies quotas to the API project; changing the model or creating another key in the same project cannot bypass a project-wide limit. If the shared demo key is exhausted, wait for its quota reset or use a Gemini key from a separate project that you control.

Admin → AI models has an optional tab-scoped Gemini key. That key is held in this browser tab's session storage and is cleared when the tab closes. Signed-in users can separately save an encrypted account key in Account & History; the Worker decrypts it only for provider requests. These are separate key-management paths. Only enter a key you own and trust this website to use; never share it in a screenshot or message.

6. Admin / Settings

The quick-jump tiles near the top go directly to:

  • General: default response language.
  • Camera & Devices: ESP32-CAM base URL, connection test, LED brightness, stream controls and phone-photo confirmation.
  • AI & Intelligence: ranked vision models, model refresh, fallback information, tab-scoped personal API key, response wait time, description detail and optional extra prompt.
  • Voice & Accessibility: speech input mode, browser recognition language, device voice, voice style, rate and pitch.
  • SOS & Triggers: trusted-contact details, optional shake trigger and optional voice trigger. Sender/receiver pairing remains in the SOS Center.
  • Testing tools: use Image Lab to select a local image, load a URL or capture a camera still, then inspect the exact preview before sending.

Diagnostics is separate and tests camera, microphone, AI, speaker and backend health. Account & Data manages sign-in, existing history and saved account keys.

App preferences are saved in this browser on this device. The Admin API key is tab-scoped; the signed-in account key is stored encrypted by the Worker. Clearing browser data can remove local preferences and guest-history access.

7. Diagnostics and common errors

Camera fetch failed: check the IP, Wi-Fi and whether /capture returns an image directly. Browser CORS or private-network rules may still block the app.

Microphone permission denied: use the HTTPS live website, allow microphone access in browser site settings and retry.

Speech service cannot connect: the app should attempt Gemini transcription fallback. If that also fails, check internet connectivity, the selected API key and remaining model quota, or type the question instead.

Gemini 429 / quota: the current model or shared project may be out of requests or tokens. Automatic switching handles model-specific limits only. Try your own key from a separate project or wait for reset.

No sound: increase device volume, check silent mode, choose an installed voice in Admin and use the speaker test. Some mobile browsers require a direct tap before playback.

Check all at once: it runs an actual image request if an image is available and therefore consumes AI quota. Use individual tests when you only need to inspect one device component.

8. Set up the SOS receiver

  1. On the sender phone, open the SOS Center, select the Sender tab and choose Generate receiver pairing code.
  2. On the trusted person's phone, open the SOS Center, choose the Receiver tab and enter the six-character code before it expires.
  3. On the receiver, tap Enable Emergency Siren & Notifications. Keep the browser tab open, the phone charged, volume on and network connected.
  4. Generate a new code to replace the previous receiver. The old receiver session is revoked.

Mobile operating systems may suspend or close background pages. An alert may not arrive or make sound when a phone is locked, offline or the browser is suspended. Do not rely on SOS as an emergency service.

9. Privacy, safety and support

Camera images are sent to the app backend and, in Gemini mode, Google Gemini for analysis. Photo history is currently off by default; no new photo should be assumed saved unless history is explicitly enabled and the service is configured. Recorded voice audio may be sent to Gemini for transcription and is not intentionally stored in photo history. An Admin key is tab-scoped; signed-in users can separately save an encrypted account key. See Privacy for details.

This is an experimental assistive tool, not a certified navigation aid or medical device. AI can miss hazards, misread text or produce incorrect answers. Do not use it to decide whether to cross a road, walk through an area or avoid an obstacle. Continue using a white cane, guide dog, mobility training and human assistance.

For support, run Diagnostics and share the text output, but remove API keys, pairing codes, private images and other personal details first. Use the Contact page for current support channels.
