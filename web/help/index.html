GUIDE & SUPPORT

Help and instructions

How to use the camera, ask a question, get speech working and pair SOS.

1. Start with the four actions

DESCRIBE — understand the scene

Tap DESCRIBE. Daredevil's Eye captures one still photo from the configured ESP32-CAM and sends it to the vision model. The assistant gives a concise description of visible objects and context. Keep the camera steady and make sure the subject is in the frame. A photo can be unclear, dark or partly blocked, so the assistant may report uncertainty.

ASK AI — ask about the current view

Tap ASK AI, wait for the listening message, then ask one clear question. Pause when finished so the recording can stop. You can also type a question on the normal home page. The current camera image is included as context. Ask questions such as “What is on the table?” or “What does this label say?” Results depend on image quality and model ability.

SOS — notify your paired receiver

SOS sends an alert through the app to the receiver paired in advance. It does not silently phone emergency services, detect falls or guarantee delivery. A separate phone link may be offered for a call to the trusted contact saved in Admin.

HELP — find instructions

Open this page or choose Help inside Blind mode. The menu at the top of standard pages provides shortcuts to the other sections.

2. Use Blind mode

Open Blind mode for a full-screen 2-by-2 layout with only DESCRIBE, ASK AI, SOS and HELP. The title and navigation menu are intentionally absent so the entire screen is dedicated to four large touch targets.

To leave Blind mode, edit the browser address and remove /blind/, or navigate directly to /action/. There is deliberately no exit control on the Blind mode screen. The Help tile has a Return to the four actions link.

3. Camera setup and photo fallback

Open Admin / Settings → Camera & SOS. Enter the ESP32-CAM base address, for example 192.168.0.104. The app adds http:// automatically and requests the camera's /capture endpoint. The phone and camera must be on a network that allows that request. A local private IP works only on its local network; the hosted website cannot reach your home or lab camera from anywhere in the world.

On the normal Home page, use “Use phone camera / upload photo” when the ESP32-CAM is unavailable. Choose a clear JPEG, PNG or WebP image. Never expose an unauthenticated camera web server directly to the public Internet.

4. Voice input and language

The microphone needs a secure HTTPS website (or localhost on a development computer). Plain HTTP LAN addresses such as http://192.168.x.x are not secure contexts for browser microphone access. Allow microphone permission in the browser and close other apps that may be using the microphone.

Some browsers use an external speech-recognition service. When it reports that it cannot connect, Daredevil's Eye attempts a different path: it records a short clip in the browser and sends it to Gemini for transcription. Gemini detects the spoken language from the words, not from the accent. Bengali speech is translated into English for the question; English speech remains English, including English spoken with a Bangladeshi accent. If this fallback is unavailable, type your question on the standard Home page.

The fallback uses an audio understanding/transcription model and can use Gemini quota. The browser stops recording after a pause or a short time limit. Do not speak passwords, private details or confidential information.

Response language in Admin controls the written answer preference. A recogniser's accent detection is not the same as identifying whether the words themselves are Bengali or English.

5. Models, automatic fallback and your own key

The Admin model list is ranked for image understanding: models that can analyse camera photos appear before lower-cost Flash or Flash-Lite options. It is not a list of image-generation models. An image-generation-only model creates a picture and is not suitable for describing a photo from the camera.

When a model-specific limit, overload or temporary availability error occurs, the Worker tries other compatible Gemini models. This is best-effort fallback. Google applies quotas to the API project; changing the model or creating another key in the same project cannot bypass a project-wide limit. If the shared demo key is exhausted, wait for its quota reset or use a Gemini key from a separate project that you control.

Admin → AI models has an optional “Use your own Gemini API key” box. Your key is stored in this browser tab's session storage, not in the app database or Admin preferences. It is sent only to this site's API request. Close the tab to clear the session key, or press Remove my key. Only enter a key you own and trust this website to use; never share it in a screenshot or message.

6. Admin / Settings

The quick-jump tiles near the top go directly to:

  • Camera & SOS: camera base URL, trusted-contact details, receiver invitation code and response language.
  • AI models: ranked vision models, model refresh, fallback information, personal API key, response wait time, description detail and optional extra prompt.
  • Voice: device voice, voice style, rate and pitch. Device speech is the default because it does not use another AI request.
  • Image tester: select a local image, load an image URL or capture a camera still; inspect the exact preview before sending.
  • Diagnostics: use the six-card checkup to test camera, microphone, AI, speaker, system and all checks together.
  • Home: return to the regular action screen.

Settings other than the tab-only personal API key are saved in this browser on this device. Clearing browser data can remove them.

7. Diagnostics and common errors

Camera fetch failed: check the IP, Wi-Fi and whether /capture returns an image directly. Browser CORS or private-network rules may still block the app.

Microphone permission denied: use the HTTPS live website, allow microphone access in browser site settings and retry.

Speech service cannot connect: the app should attempt Gemini transcription fallback. If that also fails, check internet connectivity, the selected API key and remaining model quota, or type the question instead.

Gemini 429 / quota: the current model or shared project may be out of requests or tokens. Automatic switching handles model-specific limits only. Try your own key from a separate project or wait for reset.

No sound: increase device volume, check silent mode, choose an installed voice in Admin and use the speaker test. Some mobile browsers require a direct tap before playback.

Check all at once: it runs an actual image request if an image is available and therefore consumes AI quota. Use individual tests when you only need to inspect one device component.

8. Set up the SOS receiver

  1. On the sender phone, open Admin / Settings and choose Generate pairing code in Camera & trusted contact.
  2. On the trusted person's phone, open SOS Receiver and enter the six-character code before it expires.
  3. On the receiver, tap Enable alarm & start listening. Keep the browser tab open, the phone charged, volume on and network connected.
  4. Generate a new code to replace the previous receiver. The old receiver session is revoked.

Mobile operating systems may suspend or close background pages. An alert may not arrive or make sound when a phone is locked, offline or the browser is suspended. Do not rely on SOS as an emergency service.

9. Privacy, safety and support

Camera images are sent to the app backend and Gemini for analysis. If native browser recognition is unavailable, recorded voice audio is sent to Gemini for transcription. This app does not intentionally store image or audio payloads. Your personal API key stays in the current browser tab session. See Privacy for details.

This is an experimental assistive tool, not a certified navigation aid or medical device. AI can miss hazards, misread text or produce incorrect answers. Do not use it to decide whether to cross a road, walk through an area or avoid an obstacle. Continue using a white cane, guide dog, mobility training and human assistance.

For support, run Diagnostics and share the text output, but remove API keys, pairing codes, private images and other personal details first. You can contact the project maintainer at 01735530174 or WhatsApp.
