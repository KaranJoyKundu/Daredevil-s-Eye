RC522 wiring reference

The hardware connection is unchanged. Actual ESP32-to-cloud scans still require secure device authentication; this temporary page test does not bypass that security.

RC522  →  ESP32
SDA/SS →  GPIO 5
SCK    →  GPIO 18
MOSI   →  GPIO 23
MISO   →  GPIO 19
RST    →  GPIO 22
3.3V   →  3V3
GND    →  GND

Use 3.3V only. The reader's SDA pin is SPI chip-select, not I²C SDA.
